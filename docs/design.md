# Touchline design

Hallmark v2.0.0. Scope: app screen. Poppins is locally hosted in weights 400, 500, 600 and 700. Neutral greys distinguish the goal feed, video details and match rail. Deep green identifies selected goals, active matches and primary actions. These choices follow the user's current direction and supersede the earlier Kiln ember palette and Georgia wordmark.

The dashboard fills the viewport, with fluid columns and internal list scrolling. This full-width behaviour is explicitly requested. On phones, goals and playback share the available area; Matches opens as a drawer. Favourite clubs and connections live in Settings. One toolbar contains feed filters and viewing controls. No duplicate team/score strip appears above the video; player tools sit beside the source link below it.

Use consistent 12px content insets, 16–24px desktop column gaps and an 8px phone edge. Density comes from clear type and concise information, with sufficient room around selectable rows. Preserve real footage, original-source attribution, official crests, spoiler privacy, keyboard navigation and playback recovery. Sample metadata is explicitly fictional and contains no supplied footage.

Every loading region retains loading, empty, error and full states. Only scorer changes receive a short state transition, with a reduced-motion fallback. Focus is immediate, and input edges meet 3:1 contrast. No marketing sections, fabricated statistics or decorative footage overlays.
