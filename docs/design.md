# Touchline design

Hallmark v2.0.0. Scope: app screen. Poppins is locally hosted in weights 400, 500, 600 and 700. Neutral greys distinguish the goal feed, video details and match cards. The supplied palette provides burnt orange (#AC4000) and deep green (#005219). Orange marks unwatched goals with a brighter row, minute and play cue; watched goals recede onto a darker background with a checkmark. Green identifies the active goal, active matches and primary actions. Muted, darker derivatives of the supplied palette keep the selected state restrained; lighter accent tokens keep text and indicators legible. These choices follow the user's current direction and supersede the earlier Kiln ember palette and Georgia wordmark.

The dashboard fills the viewport, with fluid columns and internal list scrolling. This full-width behaviour is explicitly requested. On phones, goals and playback share the available area. Dashboard, Following, Ones to watch and Matches share a single header navigation row; narrow screens scroll that row and bring the active destination into view. Matches is a dedicated page of recent games and fixtures. Favourite clubs and connections live in Settings, whose section navigation also stays in the header. Goal search and viewing controls share the header on desktop. On phones, a search icon expands the input within the same header, keeping navigation on one row; manual import remains available through Connections. No duplicate team/score strip appears above the video; player tools sit beside the source link below it.

Use an edge-to-edge dashboard with a 4px column separation, a compact 40px list header, and a 240–300px adaptive goal list beside a flexible player. Watched markers share the trailing control column instead of adding another metadata line. Density comes from clear type and concise information, with sufficient room around selectable rows. Preserve real footage, original-source attribution, official crests, spoiler privacy, keyboard navigation and playback recovery. Sample metadata is explicitly fictional and contains no supplied footage.

Every loading region retains loading, empty, error and full states. Only scorer changes receive a short state transition, with a reduced-motion fallback. Focus is immediate, and input edges meet 3:1 contrast. No marketing sections, fabricated statistics or decorative footage overlays.

Seen state updates optimistically when a goal is opened and saves in the background. The automatically opened desktop clip is included; phone selections do not count until the player opens. Spoiler-protected goals count after reveal. Marking the open goal as unwatched stays respected until it is opened again.
